# 📝 Soal Latihan: Pertemuan 01 (Pengenalan Python & Variabel)

Kerjakan soal-soal latihan berikut pada file `latihan_mandiri.py` untuk mempraktikkan materi pengenalan Python dan variabel yang telah dipelajari.

## 📌 Soal 1: Koreksi Penamaan Variabel
Di bawah ini terdapat beberapa baris kode dengan penamaan variabel yang salah (akan memicu `SyntaxError`). Identifikasi kesalahannya dan tuliskan versi penamaan variabel yang benar sesuai konvensi **PEP 8 (snake_case)**:

```python
# Kode Bermasalah:
1nama = "Budi Santoso"
nama lengkap = "Budi Santoso"
harga-barang = 50000
for = "Perulangan"
```

**Tugas Anda:**
Tuliskan variabel-variabel di atas dengan nama yang benar dan berikan nilai yang sesuai di lembar kerja Anda.

## 📌 Soal 2: Eksplorasi 4 Tipe Data Primitif
Deklarasikan dan inisialisasikan 4 variabel dengan tipe data berbeda:
1. `nama_laptop` (bertipe `str`)
2. `kapasitas_ram_gb` (bertipe `int`)
3. `ukuran_layar_inci` (bertipe `float`)
4. `memiliki_garansi` (bertipe `bool`)

Cetak nilai dari masing-masing variabel beserta tipe datanya ke konsol menggunakan fungsi `type()`.

## 📌 Soal 3: Pembuatan Kartu Profil Mahasiswa / Siswa
Buatlah variabel-variabel berikut:
- `nama_lengkap`
- `asal_sekolah`
- `hobi`
- `alasan_belajar_python`

Tampilkan sebuah kartu profil yang tersusun rapi menggunakan **f-string** dengan bingkai garis strip (`-` atau `=`).

Contoh format tampilan yang diharapkan:
```
==================================================
              KARTU PROFIL BELAJAR
==================================================
Nama Lengkap  : Maya Safira
Asal Instansi : SMAN 1 Jakarta
Hobi          : Desain & Membaca
Tujuan Belajar: Ingin membuat program otomasi sendiri
==================================================
```
