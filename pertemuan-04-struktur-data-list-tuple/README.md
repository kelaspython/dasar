# Pertemuan 04: Struktur Data (List & Tuple)

Pada modul keempat ini, kita masuk ke pembahasan struktur data sekuensial yang menjadi tulang punggung pemrosesan data di Python: **List** dan **Tuple**.

---

## 🎯 Tujuan Pembelajaran
1. Memahami konsep struktur data koleksi berurutan.
2. Menguasai teknik *positive/negative indexing* dan *slicing*.
3. Menggunakan operasi mutasi list (`append`, `insert`, `pop`, `remove`, `sort`).
4. Menggunakan *list comprehension* untuk transformasi data.
5. Memahami sifat kekekalan (*immutability*) pada Tuple dan teknik *unpacking*.
