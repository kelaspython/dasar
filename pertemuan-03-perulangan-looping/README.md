# Pertemuan 03: Perulangan (Looping) di Python

Pada modul pertemuan ketiga ini, kita akan mempelajari teknik otomatisasi eksekusi kode berulang menggunakan `for` dan `while` loop, teknik pengendalian iterasi, hingga pembuatan algoritma pola dan logika interaktif.

---

## 🎯 Tujuan Pembelajaran
1. Memahami perbedaan skenario penggunaan `for` loop dan `while` loop.
2. Menguasai fungsi `range(start, stop, step)` untuk iterasi berhitung.
3. Mencegah bug *infinite loop* saat bekerja dengan `while`.
4. Mengendalikan alur iterasi menggunakan `break` dan `continue`.
5. Menerapkan *nested loop* untuk pemrosesan matriks/tabel atau pola geometris.
